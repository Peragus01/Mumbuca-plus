# Redesign C2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplicar o tema visual C2 ("Identidade Maricá, escuro total") a todo o frontend, sem mudar lógica, API nem comportamento.

**Architecture:** O tema muda pelos tokens CSS em `frontend/src/styles.css` (`:root`), com ajustes de marcação pontuais em Login, CitizenView, RechargeDialog, OperatorView e StatusBadge. Não entra nenhuma dependência nova. Os testes existentes continuam como rede de segurança, e cada tarefa acrescenta testes para os elementos estruturais novos.

**Tech Stack:** React 19, Vite, CSS puro, vitest + @testing-library/react (jsdom).

**Spec:** `docs/superpowers/specs/2026-11-24-redesign-c2-design.md`

## Global Constraints

- Fundo `#06150f`; texto `#eef6f1`; acento primário amarelo `#ffd23f`; acento de sucesso/on-chain verde-neon `#3dffa8`.
- Saldo com `linear-gradient(90deg,#ffd23f,#3dffa8)` em `background-clip:text`, mais um fallback de cor sólida (`color: #ffd23f`) antes do gradiente.
- Contraste de texto e controles WCAG AA sobre o fundo. Foco visível em amarelo.
- Sem dependências novas e sem recursos externos em runtime (fontes, CDN, imagens): pilha de fontes do sistema.
- O QR Code do Pix fica sempre sobre uma moldura clara (fundo `#ffffff`, padding de pelo menos 12px).
- Sem alternância claro/escuro. Sem o botão "Onde usar".
- Link da carteira: `https://explorer.solana.com/address/<endereço>?cluster=devnet`.
- Regras existentes preservadas:
  - a origem (`SIMULADO`/`OZAV …`) nunca aparece na visão da cidadã;
  - respostas antigas são descartadas ao trocar de conta;
  - o polling para em MINTED/FAILED;
  - sem rolagem lateral a 375px.
- Testes existentes: só podem ser ajustados quando um texto ou papel de acessibilidade mudar de propósito, e cada ajuste precisa ser justificado no relatório.

## Review Focus

1. **QR ilegível no tema escuro:** o QR precisa ficar dentro de uma moldura clara. É verificado pelo teste da Task 2: o contêiner do QR tem a classe `qr-frame`.
2. **Navegador sem suporte a `background-clip:text`:** o saldo continua legível pela cor sólida de fallback. É verificado na revisão do CSS da Task 2.
3. **Tela de 375px:** a tabela do operador e o cartão de saldo não rolam para o lado. É verificado manualmente na Task 3, com captura de tela.
4. **Botão "Ver na rede" da cidadã:** o link aponta para o endereço da conta selecionada, com `target="_blank"` e `rel="noopener noreferrer"`. É verificado pelo teste da Task 2.
5. **Contraste dos selos de status e dos alertas:** o texto sempre aparece junto da cor, nunca só a cor. Isso é garantido pelos testes existentes de StatusBadge (texto) e verificado na revisão da Task 3.
